## 存放与校验

GitHub 只保存工具、说明和校验索引。大型归档保存在操作者本机，
`PRIVATE_REVIEW_NOT_FOR_GITHUB` 的证据包可能包含生产配置等私有内容，
不得作为公开附件上传。迁移目标必须限制访问权限，并在迁移后重新校验。
当前尚未选择异机存储，因此 **异机备份待完成**。

把本批文件放在同一目录后，Linux 可以执行：

```bash
sha256sum -c SHA256SUMS
python3 archive_local.py --verify historical-packages-and-evidence.private.tar
```

验证归档只读取成员，不解压、不执行内部脚本。外层摘要需要与可信的 GitHub
索引核对；只使用归档自己携带的清单，不能证明文件在传输前未被替换。
`archive_local.py` 的创建模式需要原始本地材料；验证模式不需要这些材料。
不要重复执行创建模式覆盖现有输出；它要求一个全新的目录。
若私有包已通过校验而源码导出尚未完成，可使用 `--resume` 重新核对并复用私有包；
已有最终源码包、索引或校验清单时仍拒绝覆盖。
首次 `git archive` 导出因 Windows 脚本换行转换未通过原始字节核对，已移出
交付目录并单独保留；仅 `production-source-523f1f0f-raw.tar.gz` 是本批源码快照。
Git 属性明确禁止转换索引及校验清单的换行符，确保仓库与交付文件摘要相同。
