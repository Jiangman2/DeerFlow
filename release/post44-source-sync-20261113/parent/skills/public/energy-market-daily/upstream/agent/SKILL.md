# 最终日报工作流

本文件位于迁移包agent目录。所有路径以迁移包根目录为基准，不依赖原电脑用户名或Codex应用。

读取 `../docs/01-STYLE.md`、`../docs/02-API.md`、`../docs/03-ACQUISITION.md`、`../docs/04-EXECUTION.md`。数据字段见 `../docs/05-DATA-CONTRACT.md`。环境不匹配时参照 `../docs/06-DEPLOYMENT.md`。

不可违反的约束：

- 样式冻结，使用 `app/report_renderer.py`，不得另写HTML或缩小所有字体来容纳长新闻。
- 北京时间发布日期D，行情日T=D−1自然日；指定历史数据日时按用户给定日期，通常对应次日发布。新闻不能晚于该期D和截稿时间。
- 油气与运费从金凯讯API取数，三个月滚动窗口；金融与资讯由网络搜索、原页核验取得。不用独立金融API偷偷取代搜索流程。
- 天然气标签为Henry Hub、JKM、TTF。Henry Hub右轴。运费保留四条航线的整船/每桶表格，仅一张整船万美元走势图。
- 金融值必须是T日已完成收盘；休市/缺失显示“—”，不复制前值。前值同口径才能算涨跌。
- 公司动态不少于五条独立重大事件，市场新闻通常3—5条；不能把同一公告拆条凑数。未核实够五条不能标记本期完成。
- 生僻外国公司/人名保留英文并加国家、类型或职务；国家名中文，壳牌等熟悉公司可中文。详情见取数规则。
- 每期先归档证据、保存快照、校验，再渲染HTML/PNG/JSON。图表不补非交易日值，未更新处断线，不跨单位连线。
- 本迁移包按企业定时已开启场景配置（enabled=true）：北京时间周二至周六06:00—23:55，每5分钟触发，完成后每天只出一版。企业平台需实际注册并开启调度；本包不会自行启动常驻服务。用户后续要求暂停时立即停止。本配置不恢复原电脑的Codex任务，也不授权外发报告。

首次迁移先执行 `python tools/reproduce.py --strict`，通过基准图验收再运行新期次。不要拿历史provenance中的已弃用规则覆盖本规则。
