# 最终样式规范

唯一模板：`app/report_renderer.py`。冻结HTML含内联CSS及SVG，无在线JS、无外链字体。PNG由浏览器全页截图，视口390×844 CSS像素、deviceScaleFactor=2，因此图片宽780像素，高度随新闻长度变化。320/390/430宽度必须无横向溢出。最大内容宽460px，桌面居中；手机白底、外围#eef1f4。

## 从上到下

1. 标题“油气与金融市场日报”。下方只出现“发布日期：YYYY.MM.DD”“数据日期：YYYY.MM.DD”“能源经济研究院”。
2. 原油市场：布伦特原油期货、布伦特原油现货、WTI 原油期货，一行三格；价格、美元/桶、较前一交易日百分比。无上海原油SC。近三个月三条折线，数据来源：金凯讯。
3. 天然气市场：Henry Hub、JKM、TTF，一行三格；美元/百万BTU，报价3位小数。三个月图，Henry Hub独立右轴，图例写Henry Hub（右轴）；其他两条左轴。来源：金凯讯。不要恢复“LNG JKM”“TTF天然气期货”“当周累计均价”说明。
4. 航运运费：四条航线表格，列为航线、整船口径、每桶口径；每格数值/单位/涨跌。依次西非—中国、阿曼湾—中国、美湾—中国、波斯湾—中国。仅一张整船（万美元）四线图，与油气三个月同起止日。每桶数据保留在表格，不再绘图。来源及图口径写图下。
5. 石油公司与股市：右侧“收盘价｜较前一交易日”，单行。第一行海油 A 股、海油港股并列；第二行中石油、中石化、沪A指数。
6. 汇率与美元：美元指数、美元兑人民币两格。日线收盘；只有实际采用16:30口径时标注16:30，不能强行固定。
7. 油气市场重要新闻：通常3—5条，短标题加事实摘要、段尾来源/日期/链接。
8. 石油公司动态：不少于5条，通常5条保持紧凑；序号自动连续。无“预留”“可扩展至5条”等字样。
9. 页脚分为注、行情、新闻三行，左侧标签固定宽30px。注包含“走势图不对非交易日数据进行补值”，有未更新和运费口径说明。行情来源按实际快照汇总；新闻“来源见段尾标注”。

无“模拟”“样稿”“用户提供”“不构成投资建议”。本包可称迁移样例，但成品日报正文不加这些标签。

## 字体及颜色

正文CSS顺序：`Microsoft YaHei`, `PingFang SC`, `sans-serif`。价格数字：Arial、Microsoft YaHei、sans-serif。当前Windows实际基准使用微软雅黑和Arial，字体文件与哈希见 `config/font-manifest.json`。PingFang为原模板兼容回退，不代表与微软雅黑字宽相同。

图表SVG viewBox 366×135，横轴真实日期线性定位，四个日期刻度；非交易日不插值/补值，跨周末连接已有交易点不等于补造数值。“未更新”在折线中断开。轴范围根据当前序列计算，不锁死样例刻度。所有运费图例颜色按固定航线顺序；单位变化时保留原值原单位，不能接入万美元图，必须在表及说明提示。
