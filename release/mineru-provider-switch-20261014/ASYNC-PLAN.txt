2. Build the candidate over that base; verify only the approved Adapter source
   delta, no dependency re-resolve, existing CA/runtime preserved. Run fixtures.
3. From the enterprise network, use a hidden-input runtime credential to submit
   one synthetic asynchronous PDF, poll its same ID and verify Markdown/images.
   Stop on uncertain submission; never automatically resubmit it.
4. With approved fixed samples, measure old/new endpoints and full application
   separately: 5/20/100-page scans, mixed text/figures/tables, and chat uploads.
   Gate each level (8,16,32,64) before increasing, with bounded counts/time/memory.
   Report pages/sec, batch duration, per-task P50/P95/P99, failure and incomplete

5. Keep the 64 upper-limit request explicit. If 64 is worse than 32 for either
   reliability or interactive latency, report the evidence and obtain the final
   operating-point choice instead of silently claiming the goal was achieved.
6. Only after these gates: one controlled rollout with old-image/old-config
   rollback. Do not change the Nginx knowledge-entry gray-out or unrelated work.
