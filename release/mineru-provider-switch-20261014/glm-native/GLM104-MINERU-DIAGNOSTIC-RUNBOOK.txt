current App UID. Do not run obsolete88 observers or replay the104 mutator.

dispatcher logs, previous worker containers when a restart exists, and safe

not provider submissions. Health GETs can run the dispatcher's already-existing

writes no files. Diagnostic COMPLETE means collection completed, NOT runtime
acceptance or expansion permission. INCOMPLETE still retains printed evidence.
