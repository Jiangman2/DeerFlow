# Read-only GLM104 pipeline diagnosis

Keep MinerU16 and WeKnora104 unchanged. This release reads the exact acknowledged
App/adapter identities through the hash-bound prior diagnostic loader. Never
invoke an old mutation CLI, signal a Pod, retry a task, modify Redis, change a
database/index/permission, enable profiling, or call a provider.

Use bounded SQL with default/read-only transactions and statement/lock timeouts.
Require an indexed LIMIT plan before sampling recent processing spans. Neither
document IDs/content nor SQL text/provider responses leave the process. Stream
existing Kubernetes logs into bounded numeric/category aggregates, not raw
files; identify gaps, truncation and restart/identity changes explicitly. Kill
only the tool's own local kubectl subprocess when closing a log reader.

Model Redis holders are unexpired leases, not provider jobs or local waiters.
Image spans are inclusive read/VLM/index intervals, not pure GLM latency.
Collection completion is never tuning approval or throughput acceptance.
Qualify source and exact single-file delivery on real Python3.7 and modern
Python, with synthetic streaming/cgroup/SQL tests; no production calls in tests.
