# 海能 Work 集成功能更新

候选日期 2026 年 11 月 6 日，基于 0716 分支。

| 功能 | 使用方式 |
| --- | --- |
| 日历确认与回执 | 创建或修改日程前，点预览卡片上的「确认执行」或「取消本次修改」。缺标题时直接回复标题即可，已填写的时间等条件会保留。预览和结果按北京时间展示，单条和批量操作有简明回执。卡片不可用时会显示文字确认方式。 |
| 按名称查找并读取云文件 | 例如「读取云盘里的《团队日报汇总》」。搜索完整且只有一个精确同名文件时直接进入读取流程。出现多个候选时，可以点「读取 1」「读取 2」，也可以直接回复序号。按钮对应所在卡片，直接回复序号对应当前列表，候选保留 5 分钟。选中后原卡片显示进度，随后展示授权入口或读取结果。 |
| 读取更多文件类型 | 可以读取原生云文档、在线表格、多维表格，以及上传到云盘的 DOCX、XLSX、PDF。较大的表格提供有限预览，扫描 PDF 需要可用的企业解析服务。按名称搜索和读取正文分别检查当前用户的授权。 |
| 定时任务私聊通知 | 创建或编辑定时任务时，可在「海能 Work 通知」里选择已绑定的个人私聊。定时触发和手动运行成功后都可推送简报，运行历史会单独显示发送状态，并可打开完整结果。 |

配置和发布顺序见 [Work 生产配置](WORK_PRODUCTION.md)。日历和搜索卡片使用已发布的 `card.action.trigger` 回调。海能 Work 按名称搜索使用用户身份权限 `drive:drive:readonly`，正文读取权限按文件类型配置。私聊通知需要接收者已绑定且经过验证的会话。

本次增量使用现有 PostgreSQL `0022_work_integration_state`。启用前先让 Gateway 加载一致的镜像和配置，再核对正式应用权限与回调发布状态。定时任务设置和运行历史的入口随 Frontend 更新。
