# 关于中海油勘探开发通用智能体

中海油勘探开发通用智能体是面向油气勘探开发业务的多智能体工作平台，基于上游 2.0 官方主分支能力构建，并保留官方 gateway auth 认证体系。

## 平台能力

- 深度研究：围绕专业问题进行资料收集、分析与结构化输出。
- 数据分析：支持文件、表格、图表与业务数据处理。
- 报告生成：面向科研报告、审查材料、汇报材料等场景生成内容。
- 技能扩展：通过内置与自定义 Skill 持续扩展业务能力。
- 安全工作区：在受控工作区内进行文件读写、转换与产物生成。

## 说明

当前版本跟踪上游 2.0 官方 main，并在此基础上迁移中海油品牌前端、业务技能和智能体配置。
