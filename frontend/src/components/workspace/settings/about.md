# 关于中海油智能体应用平台

中海油智能体应用平台面向油气业务的智能研究与协同作业场景，提供统一工作台、对话线程管理、文档与知识接入、工具编排与产物沉淀能力，支撑业务分析、方案编制与知识复用等任务。
