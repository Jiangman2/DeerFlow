# 日报数据与资讯获取规则

## 日期与交易口径

以北京时间确定发布日期D，行情数据日期为D前一个自然日T。记录本次检索截止时间（北京时间）。修订历史期次时使用该期D、T，不随当前日期变化。新闻可包含D日截至检索时间已发布的报道；新闻日期在段尾逐条标明，不能把新闻的日期要求与行情T日要求混为一谈。

各市场按其交易日标签取T日已完成收盘的数据，记录市场时区及收盘口径，不混入D日盘中数。若T日休市，显示“—”并记录休市状态；不将前值复制成T日价格，不制造0%涨跌。T日应交易但未查到价格时记录“缺失/待核实”，不能猜测为休市。涨跌比较T与该品种前一个有效交易日P，P不一定是T减一天。走势图不对非交易日数据进行补值。

每次按“代码/准确名称＋T日期＋收盘价/涨跌幅”搜索，并查询P日收盘或T日昨收。美元指数可用英文“US dollar index + 日期 + close”，人民币用“在岸人民币 + 日期 + 收盘”。关键词无效时改用日期格式、交易所代码、站内搜索和行情历史页，不能只重复同一失败查询。

来源优先级：交易所、指数发布方及官方市场披露；其次可靠金融行情历史页（如腾讯财经、新浪财经等）和新华社、主流证券财经媒体的明确收盘报道。需进入正文或历史行情页面，核对证券代码、交易日期、币种、收盘状态和价格类型。搜索摘要、AI摘要、标题、实时行情框、没有日期的页面不能单独作为数值依据。正式来源名称随实际采用来源记录，不能不论取自哪里都固定写成腾讯或新浪。

原则上以同一可靠来源的T、P两日数据计算；来源仅给T及涨跌时可使用明确报告的百分比，但标记 `change_method=reported`，不反推一个虚构P值。可取得前值时，按 `(T收盘/P收盘-1)×100` 计算，原值保留精度，显示两位百分比，USD/CNY显示四位报价。有除权除息等导致报告涨跌与简单收盘比不一致时，核对官方昨收参考价并记录实际比较基准，不混用复权价格。

优先使用已核实的一手数据。二手媒体取数、口径含混或结果冲突时，寻找另一独立来源复核；同稿转载不算独立来源。冲突时先检查交易日、时区、A/H股、盘中/收盘、前复权/不复权及人民币中间价/在岸价，无法解决则保留缺失并说明，禁止平均两个冲突报价或挑选看起来合理的值。

## 新闻搜索与选编

两类栏目均进行中英文检索，以最近24小时为首轮窗口。优先新华社、监管机构、政府、IEA/OPEC等机构和公司投资者关系公告；路透等权威财经媒体可补充跨国新闻。公司公告关于经营事实是一手来源，其预测、目标与观点应明确归属于公司，不写成已实现事实。

市场新闻关注重大地缘事件、能源政策制裁、市场制度、重要宏观变化及供需运输冲击，不硬凑供给与需求各一条。公司动态优先大型并购、季度业绩与指引、资本回报、重大投资决定及跨国长协，不固定凑齐中石油、中海油、中石化；可以以国际公司为主。遵循SKILL.md中的英文名称及身份标注规则。

油气市场新闻通常3—5条；石油公司动态每日不少于5条，通常选5条以保持紧凑，不设5条上限。公司动态不足时先扩大国内外公司和权威来源覆盖，再扩展到72小时和最近7日，保留真实发布日期，不将旧文写成当日新闻。仍不足5条时继续补采并明确尚未达到出稿要求，不交付为完成日报；不得用空位、重复拆条、琐碎宣传或虚构新闻满足数量。生成校验应对当前及后续期次执行至少5条要求，不能用shortfall_reason绕过公司动态数量下限；历史存档不自动改写。

阅读原文，记录媒体发布时间、事件发生时间、交易状态、币种和数值单位。对“拟收购”“已签约”“已交割”“有条件供气”“最终投资决定”准确区分。每条写成短标题和事实摘要，保留对结论有实质影响的条件，段尾标注来源、日期和原文链接。不要根据价格涨跌自行推断新闻因果。

同一事件多家转载合并为一条，优先原始公告或权威原稿；两栏目之间避免重复。同一公司财报与回购通常合并。对照最近几期防止重复报送，只有重大新增进展才再次入选，并说明新变化。需要解释的背景应注明为背景，不冒充最新事件。

## 保存、失败处理与交付检查

获取和排版分开：先保存已核实的日期快照，再运行渲染；禁止渲染时直接抓取易变实时价格。行情沿用 `data/financial_T.json`，新闻沿用 `data/news_D.json`，原文证据保存在 `sources/`。在现有schema基础上扩展，不破坏渲染器。行情每项保存代码、名称、价格、币种单位、T、P及前值（可缺）、涨跌方法与数值、价格类型、来源名、原文URL、检索时间和状态；新闻保存原文标题、摘要、来源、报道日期、事件日期（可缺）、URL及检索时间。不要把付费凭证写入快照或skill。

查询失败先换关键词或同类权威来源；单个站点最多重试2次，避免无限等待。登录、验证码或付费墙挡住正文时换可核实来源，不凭搜索摘要编写完整新闻。失败不应覆盖上一份有效快照；对本期显式记录缺项，保留历史文件但不冒充本期。先写临时文件并验证，成功后替换本期文件，保证可重复生成。

输出前核对：所有行情的日期、币种、代码和比较基准；A/H股分开；涨跌计算与原值一致；无API栏目被网络行情静默替换；新闻未晚于本次截稿、原文可追溯、无重复与过期冒充；长英文名及并列海油报价在手机宽度下不溢出。若来源变化，更新对应来源说明。结果中简要说明缺失、延迟或口径仍未确认的项目。

现有项目实现可能未覆盖全部规则（如港股仍为预留、历史金融脚本走接口、新闻生成器不负责检索）。每次运行先核对实现与本规则的差异；本次只固化获取规范，不将未实施功能描述为已实现自动化。
