# 油气与运费 API

GET `http://ip91.jkx.com.cn:6688/jkx_eecc.aspx`，参数p为供应商凭证，pdate为`YYYY-MM-DD`。运行时从企业凭证库注入 `JKX_API_PASSWORD`，地址可用 `JKX_API_ENDPOINT`覆盖；亦兼容包含p参数的 `JKX_API_URL`。本包不含凭证，单独的私密移交文件用于导入企业凭证库。不要将请求URL打印到日志。

当前供应商地址使用HTTP和6688端口，企业网络需允许到该服务的出站连接；如企业要求加密传输，应由供应商提供HTTPS或企业网关，不能凭空把URL改为HTTPS后声称已支持。

## 返回与映射

## 历史与状态

窗口：T往前推三个日历月，包含两端；月底取目标月份最后有效日。样例T=2026-11-06，起点2026-08-06，共93个自然日。逐日pdate请求，不猜测未提供的批量/起止参数。顺序取数；历史请求超时30秒、最多两次。已验证的原始日响应缓存于app/sources；目标日探测必须重取，不能因早晨缓存“未更新”而永远卡住。

close为周六/周日/休市/节假日/假日 → non_trading；空串、-、--、暂无、暂无数据、未更新 → missing；两者数值均null。其余必须有限且>0，NaN/Infinity/负数/0在当前业务校验中拒绝并待核实。不能将错误页当成功。

当前14项目标日必须均有数值才进入生成；目标日确实休市时不以旧值冒充，维持WAIT_DATA并按执行规则处置。涨跌=(T/P−1)×100，P是同品种前一有效记录，必须单位相同；单位变更则change=null。历史休市不补值，missing处断线。

11月6日LPG1227最初误返元/吨，重取后修正为万美元、数值仍7521.4199；本包用修正值生成，前版本响应另归档。将来再遇单位不一致必须按原文标注/中断比较，不硬改。只绘整船万美元图，其余单位仍保存在快照，不混入图线。

`fetch_market_history.py` 获取完整窗口并校验后才原子替换energy_T.json。若中途失败，已下载且通过校验的日缓存可续用，上一份有效整期快照不覆盖。重取历史时先归档旧缓存、只更新指定日期，然后重建快照。
