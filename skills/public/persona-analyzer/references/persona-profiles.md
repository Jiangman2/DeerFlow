# 7个典型人员画像详情

本文件定义了Persona-Analyzer使用的7个典型人员画像，供标签映射时参考。

---

## 画像1：勘探地质师

| 维度 | 标签 | 说明 |
|------|------|------|
| 业务域 | DOM-EXP | 勘探业务 |
| 岗位角色 | ROL-RSCH | 研究人员 |
| 工作模式 | MOD-ONLN | 线上研究为主 |
| 交互深度 | DEP-ANALYZE | 深度分析型 |
| 决策层级 | LVL-OPER→TACT | 操作层→战术层 |
| 数据消费 | DAT-GEO | 地质物探数据 |
| 技能画像 | SKL-PETREL, SKL-GEOEAST, SKL-AI | Petrel/GeoEast/AI |

**主要工作：**
- 地震资料解释（层位追踪、断层解释、构造图编制）
- 储层预测与综合评价（属性分析、反演、AVO）
- 圈闭评价与井位论证
- 储量计算与评价
- 测井解释与砂岩薄片鉴定
