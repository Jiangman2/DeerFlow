# Persona 7维标签体系定义

本文件定义了Persona-Analyzer使用的7维标签分类体系，用于在后台对用户的岗位进行标准化标记。

---

## 维度1：业务域标签 Domain

| 标签编码 | 标签名称 | 描述 | 典型岗位 |
|---------|---------|------|---------|
| DOM-EXP | 勘探业务 | 从事地质研究、盆地评价、地震解释、储层预测、圈闭评价等 | 地质师、物探工程师、勘探主管 |
| DOM-DEV | 开发业务 | 从事油藏描述、三维地质建模、数值模拟、开发方案设计等 | 油藏工程师、开发地质师 |
| DOM-DRL | 钻完井工程 | 从事钻井设计、钻井实时监测、完井工程、压裂设计与施工等 | 钻井工程师、完井工程师、压裂工程师 |
| DOM-PROD | 生产运营 | 从事采油管理、生产监控、油气集输、注采优化、设备维护等 | 采油工程师、生产调度、操控员 |
| DOM-ENG | 地面工程 | 从事平台结构设计、FPSO设计、海底管道设计、工程建设管理等 | 结构工程师、海工工程师 |
| DOM-HSE | 安全环保 | 从事安全监督、AI视频监控、环保监测、应急管理等 | 安全工程师、环保专员、监督员 |

## 维度2：岗位角色标签 Role

| 标签编码 | 标签名称 | 描述 | 对应岗位 |
|---------|---------|------|---------|
| ROL-RSCH | 研究人员 | 以研究分析为主，使用专业软件深度工作，产出研究报告与方案 | 地质师、物探师、油藏师 |
| ROL-OPER | 现场操作人员 | 在海上平台/陆地终端进行现场操作，执行生产指令 | 采油工、中控操作员 |
| ROL-SUPV | 监督人员 | 监督施工作业、安全运营，确保合规操作 | 钻井监督、安全监督 |
| ROL-ADMN | 管理人员 | 负责生产计划调度、综合管理、团队协调 | 生产调度、作业经理 |
| ROL-MGMT | 决策人员 | 管理层，负责战略决策与资源调配 | 油田经理、分公司领导 |
| ROL-IT | IT技术人员 | 平台运维、数据管理、AI开发、系统支撑 | 数据工程师、AI算法工程师 |
| ROL-TECH | 技术专家 | 跨域技术指导、方案审核、难点攻关 | 首席专家、技术总监 |

## 维度3：工作模式标签 Mode

| 标签编码 | 标签名称 | 描述 |
|---------|---------|------|
| MOD-ONLN | 线上研究 | 主要在协同研究平台在线工作，远程分析数据 |
| MOD-FIELD | 现场作业 | 在海上平台/陆地终端一线作业，直接操作设备 |
| MOD-REMOTE | 远程操控 | 在陆地操控中心远程遥控海上设施（如台风生产模式） |
| MOD-HYBRID | 混合模式 | 线上研究 + 现场作业交替进行 |
| MOD-DISP | 调度指挥 | 在生产指挥中心统一调度、协调资源 |

## 维度4：交互深度标签 Depth

| 标签编码 | 标签名称 | 描述 |
|---------|---------|------|
| DEP-CONSUME | 消费型 | 仅查看报表、看板、工单，不产生新数据 |
| DEP-INPUT | 输入型 | 录入数据、填报报表、标记样本，产生输入数据 |
| DEP-ANALYZE | 分析型 | 使用专业软件进行深度分析、建模、模拟，产出分析成果 |
| DEP-CREATE | 创造型 | 开发算法、构建模型、设计业务流程，产出创新成果 |
| DEP-DECIDE | 决策型 | 基于分析结果做审批、决策、资源调配 |

## 维度5：决策层级标签 Level

| 标签编码 | 标签名称 | 描述 | 决策范围 |
|---------|---------|------|---------|
| LVL-STRAT | 战略层 | 集团/分公司层面战略决策 | 年度计划、重大项目投资、全局性资源配置 |
| LVL-TACT | 战术层 | 油田/项目层面方案优化、资源配置 | 方案优选、井位部署、措施调整、技术路线选择 |
| LVL-OPER | 操作层 | 日常生产操作、执行层任务 | 参数调整、执行指令、异常处置 |

## 维度6：数据消费类型标签 Data

| 标签编码 | 标签名称 | 消费数据特征 | 典型数据源 |
|---------|---------|-------------|-----------|
| DAT-GEO | 地质数据消费者 | 地震、测井、录井、岩心、分析化验数据 | SEG-Y、LAS、岩心图像 |
| DAT-RES | 油藏数据消费者 | 压力、产量、注入、PVT、试井数据 | 生产报表、压力测试 |
| DAT-REAL | 实时数据消费者 | 传感器实时数据、SCADA、视频流 | 温度/压力/流量实时值、视频 |
| DAT-COST | 经营数据消费者 | 成本、收入、KPI、综合指标 | 财务报表、考核数据 |
| DAT-ALL | 全数据消费者 | 跨域综合数据、大屏可视化、决策支持 | 数据湖全量数据 |

## 维度7：技能画像标签 Skill

| 标签编码 | 标签名称 | 关键技能 | 关联系统 |
|---------|---------|---------|---------|
| SKL-PETREL | Petrel用户 | 三维地质建模、地震解释、属性分析 | Petrel |
| SKL-GEOEAST | GeoEast用户 | 地震资料处理、偏移成像 | GeoEast, π frame |
| SKL-ECLIPSE | Eclipse用户 | 油藏数值模拟、历史拟合 | Eclipse, INTERSECT, CMG |
| SKL-AI | AI技能 | 机器学习、深度学习、算法开发 | AI人工智能平台 |
| SKL-DATA | 数据技能 | 数据分析、SQL、数据治理、Python | 数据湖、Python/R |
| SKL-SCADA | 工控技能 | SCADA/DCS/PLC操作、远程控制 | 中控系统、RTU |
| SKL-MGT | 管理技能 | 项目管理、团队管理、决策支持 | 经营分析系统 |
| SKL-VIS | 可视化技能 | 三维可视化、GIS、数字孪生 | 三维可视化引擎 |
| SKL-MECH | 机械技能 | 设备维护、故障诊断、预测性维护 | 设备管理系统 |
| SKL-CUSTOM | 自定义技能 | 用户提到的工具或技能不在预定义列表中时使用 | 由用户指定 |

## 标签组合规则

1. 业务域(DOM) + 岗位角色(ROL) 形成 **核心身份标识**
2. 核心身份 + 工作模式(MOD) + 交互深度(DEP) 形成 **行为特征描述**
3. 决策层级(LVL) + 数据消费(DAT) + 技能画像(SKL) 形成 **能力特征描述**

```
勘探地质师 = DOM-EXP + ROL-RSCH + MOD-ONLN + DEP-ANALYZE + LVL-OPER + DAT-GEO + SKL-PETREL/SKL-GEOEAST/SKL-AI
生产运营操控员 = DOM-PROD + ROL-OPER + MOD-REMOTE + DEP-CONSUME/INPUT + LVL-OPER + DAT-REAL + SKL-SCADA
钻井工程师 = DOM-DRL + ROL-TECH + MOD-HYBRID + DEP-ANALYZE + LVL-TACT + DAT-GEO/REAL + SKL-DATA
安全监督员 = DOM-HSE + ROL-SUPV + MOD-REMOTE/FIELD + DEP-CONSUME/INPUT + LVL-OPER + DAT-REAL + SKL-SCADA
指挥中心调度经理 = DOM-PROD/HSE + ROL-ADMN + MOD-DISP + DEP-DECIDE + LVL-TACT + DAT-ALL + SKL-MGT
油藏工程师 = DOM-DEV + ROL-RSCH + MOD-ONLN + DEP-ANALYZE + LVL-TACT + DAT-RES + SKL-PETREL/ECLIPSE/AI

```
