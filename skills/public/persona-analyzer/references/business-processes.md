# 各业务域流程节点定义

本文件定义了Persona-Analyzer使用的六大业务域标准流程节点，供流程映射时参考。

---

## 一、勘探业务域 业务流程节点

### 1.1 盆地评价

| 环节 | 节点 | 输入 | 输出 | 主要参与角色 |
|------|------|------|------|------------|
| 区域地质研究 | 区域构造格架分析 | 区域地质图、重力/磁力资料 | 区域构造认识 | 地质师 |
| | 沉积盆地演化研究 | 区域地质资料、古地理图 | 盆地演化模式 | 地质师 |
| 区带优选 | 含油气系统分析 | 烃源岩/储层/盖层数据 | 含油气系统评价 | 地质师 |
| | 有利区带排队 | 多因素综合评价 | 区带优先序列表 | 地质师+主管 |
| 资源评价 | 盆地级资源量计算 | 地质参数、类比数据 | 资源潜力评估 | 地质师 |

### 1.2 地震勘探

| 环节 | 节点 | 输入 | 输出 | 主要参与角色 |
|------|------|------|------|------------|
| 地震部署 | 观测系统设计 | 地质目标要求 | 采集设计方案 | 物探工程师 |
| | 采集参数优化 | 地质模型 | 优化后的采集参数 | 物探工程师 |
| 地震采集 | 海上拖缆/OBN采集 | 设计方案 | 原始地震数据 | 采集作业队 |
| | 质量监控 | 原始数据+质控标准 | QC报告 | 质控人员 |
| 地震处理 | 预处理（去噪/静校正） | 原始SEG-Y | 预处理数据体 | 处理工程师 |
| | 偏移成像 | 预处理数据体+速度模型 | 偏移数据体 | 处理工程师 |
| | AI全波形反演(AI4FWI) | 地震数据+初始模型 | 高精度速度模型 | AI工程师+处理师 |
| 地震解释 | 层位/断层解释 | 偏移数据体 | 解释成果(层位/断层) | 解释地质师 |
| | 构造成图 | 解释成果+速度场 | 构造图 | 解释地质师 |

### 1.3 储层预测

| 环节 | 节点 | 输入 | 输出 | 主要参与角色 |
|------|------|------|------|------------|
| 属性分析 | 地震属性提取 | 偏移数据体+解释层位 | 属性体/沿层属性 | 地质师 |
| 反演 | 叠前/叠后反演 | 地震数据+测井曲线 | 波阻抗/弹性参数体 | 地质师 |
| AVO分析 | AVO属性交会 | 道集数据 | 含油气检测结果 | 地质师 |
| 综合评价 | 储层分布预测 | 多信息融合 | 储层预测图 | 地质师+主管 |

### 1.4 圈闭评价与井位论证

| 环节 | 节点 | 输入 | 输出 | 主要参与角色 |
|------|------|------|------|------------|
| 圈闭成藏分析 | 圈闭有效性评价 | 构造+储层+盖层数据 | 圈闭评价结果 | 地质师 |
| 风险评价 | 地质风险评估 | 多因素概率分析 | 风险概率 | 地质师+专家 |
| 井位论证 | 探井井位设计 | 圈闭+风险评价结论 | 井位建议书 | 地质师+主管 |
