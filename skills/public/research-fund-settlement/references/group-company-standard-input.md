# 集团公司标准输入表合同

使用本 Skill 内置的 [标准输入表](../assets/reference-examples/group-company-standard-input.xlsx)，工作表名称保持 `Sheet2`，金额单位为万元。业务区域为 A:G 列；右侧备注不参与财务计算。附录2允许插入、删除整条年度行，附录3随之整体移动。保留附录标题、科目名称、业务列及业务区域合并关系，不要求固定工作表尺寸。

## 留空与自动计算

- 按用户确认的口径，资金来源和费用科目的空白金额视为未发生，按 0 处理，无需逐格填写 0。
- 批准概算额合计、年度批准额合计、实际支出总额、直接／间接经费小计及结余可以留空，由脚本根据明细计算。显式填写的数字（包括 0）和公式结果仍须与明细相符，不能用自动计算覆盖错误填写。
- 调整后预算是独立金额，留空按 0，不擅自沿用原预算。需要表示预算未调整时，应填写原预算金额或使用引用公式。
- 金额中的“未知”“待补充”等文本不视为 0。标准表之外尚未提供的审计、验收等事实也不按 0 或“无”补齐。
- 项目名称、编号、项目类型、承担单位、项目周期和编制／负责／复核人员仍需填写；非零结余、超支仍需原因。

## 公式支持

附录2／3／4金额单元格可以使用本表金额引用、加减乘除、括号、`SUM`、`ROUND`，包括 `$B$15`、`Sheet2!B15`、`SUM(B16:D16)`、`ROUND(C24-D24,2)`。导入器使用十进制数重新计算，不依赖 Excel 的旧缓存结果，也不执行宏或外部命令。

不支持跨工作表／外部文件引用、网络函数、数组／数据表公式、循环引用或其他函数。出现此类公式时，报告指出具体单元格，须改为支持的公式或核实后的数值后继续。公式有长度、引用层级及计算量上限。

标准空表将灰色汇总格预置为公式：附录2批准概算合计、各年度批准额合计和实际支出总额；附录3直接经费小计、外协实验／试验费小计的预算、调整后预算、支出和结余。年度整行增删后，导入器按科目和年度标签识别相应位置，不固定行号。

上传表中这些自动汇总格留空时，导入器在内存中补算，其它金额公式引用它们时也能取得补算结果；不会改写原始工作簿。其余空白原单元格在公式引用中仍按0处理。显式填写的金额或公式保持原样并接受核对，差异仍报错。

## 附录1：基本信息

- `B2:B9`：项目编号、项目名称、项目类型、承担单位、起止时间、报告编制人、项目负责人、财务部门负责人。
- `B10`：“编制日期”，用于报告封面底部。可填完整日期文本（如 `2026-11-05`、`2026年11月5日`）或带日期格式的 Excel 日期值；不猜测无日期格式的纯数字。空白时导入保留缺失，正式报告仍须补充。旧版没有这一行仍可导入。
- 项目类型可自由填写非空文字，保存为 `project.type_text` 并原样显示在封面；不补后缀、不规范化成预设分类。现有“集团公司”“有限公司”等写法仍可使用。自定义名称沿用标准表的有限公司模板口径，不产生税额换算；金额计算和既有税口径校验不变。
- 项目周期允许原样文本，例如 `2022年7月至2025年12月`、`2022—2025`、`以批复及延期通知为准`，直接显示于报告封面；不强制补出具体日。
- 如文本包含两个可识别的完整日期，仍检查先后顺序及年度范围。报告编制日期仍须有效；集团公司报告不要求或校验正式验收日期。

## 附录2：预算批复和支出

- `B15:D15`：三类资金来源；`E15`：任务合同书批准概算总额；`G15`：实际支出总额。
- 年度行从第16行起，到附录3之前结束，支持1至100行区域。增删整行时，让附录3及其表头、科目、合并单元格随行移动；保留每年批准额与支出额的成对年份。
- 完全未填明细金额的预留年度行，在批准额合计为空或只有计算结果为0的公式时忽略；非法公式仍报错。需要保留零金额年度时至少明确填写一个数字0；年份不得重复。
- 每行三类资金来源之和必须等于该行批准额合计；年度支出之和必须等于实际支出总额。
- 批准概算额与各年度批准额汇总属于不同批复口径，允许不一致，不得为使两者一致而改写原始金额。报告分别保留批准概算额、各年度批准额及其汇总数。

## 附录3：科目预算、支出和结余

- `B:C:D:E` 依次为预算额、调整后预算额、支出额、结余；结余等于调整后预算减支出。
- `F:G` 为结余原因。存在非零结余或超支的明细科目必须填写原因。外协实验／试验费父级原因由两个子项按顺序汇总，格式为“结余主要原因：（1）测试化验加工费，…；（2）试验费，…”，无需重复填写父级。仅汇总真实已填文字；零金额子项未填原因时不编造描述。
- 直接经费小计等于八类直接经费之和；间接经费小计等于研发人员费和依托工程费之和。
- 外协实验／试验费等于测试化验加工费与试验费之和；两个子科目不重复计入总额。
- 附录2与预算执行使用直接经费口径：附录3直接经费预算合计等于附录2批准概算总额，直接经费支出合计等于附录2实际支出总额。间接经费单独记录和展示，不加入预算执行率的分子或分母；不再要求附录2等于直接加间接。间接经费内部小计、结余和原因继续校验。
- 新导入记录 `budget_execution_scope=direct_only`。历史 `2026-09`／`2026-11` 的 `case.json` 不静默重算；要采用新口径，应从原标准表重新导入并补充事实。
- 年度行增删后，错误位置与证据定位均使用上传工作簿的实际行号。

## 导入边界

运行 `report_cli.py import-workbook` 后，只有校验报告为 `PASS` 才能进入报告流程。真实金额差异、重要文本缺失、固定标签或业务合并关系变化、工作表增删改名、缺少结余原因及不支持的公式仍会阻止导入。XLSX 仍须通过压缩包路径、部件数量、XML 大小及总解压大小边界；外部工作表关系、目录穿越、重复或加密部件均被拒绝。

标准表不包含预算变更文件明细和分科目合同／设备／工作内容明细，必要明细须从项目组材料补充。集团公司报告不要求正式验收日期，也不校验验收日期的格式或它与编制日期的先后关系；报告编制日期本身仍须有效。集团公司支出段落统一写“截至决算报告编制日”，不再为该段要求额外截止日期。概预算变更资料缺失仅作信息提示，不阻断报告生成；不得根据调整前后总额相等推断“无预算变更”，也不得虚构审批事实。

## 附录4：委托系统外单位信息

附录4在附录3之后，随年度整行增删一起移动。保留七列表头和“委托系统外单位信息”行。金额单位为万元。

- `B`：外委研究费支出总额，留空时取附录3“外委研究费”的支出额，也可填写相应金额引用公式；显式金额或公式结果必须一致。
- `C`：支付系统外单位金额，留空按0，必须在0与外委研究费支出总额之间。
- `D`：系统外金额占外委支出的比例，留空由导入器计算。填写时可使用 Excel 百分比、`20%` 文本或0至1之间的小数；非零分母时也可使用 `=C40/B40` 等公式。分母为0时请留空，不能填写除零公式。显式比例须与金额相符。
- `E:G`：系统外单位名称。可填写至多三个名称；兼容反馈样表中最后两格合并的布局，合并格下不得藏有额外金额、名称或公式。系统外金额大于0时至少填写一个真实单位名称。
- 正文分别计算“外委研究费÷直接经费”和“系统外金额÷直接经费”；这两项不能用表内“系统外金额÷外委支出”的比例替代。分母为0时不伪造比例。
- 旧版完全没有附录4时，系统外金额和单位仍属未知，不能推断为0或“无”。若之后补充审定额，外委信息必须与报告采用的支出口径核对，不能混用原实际额与审定额。
