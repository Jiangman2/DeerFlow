# 11 月 2 日已上线更新源码归档

本批对应 Gateway 401–403、Frontend 236–239，最终生产版本为 Gateway 403 / Frontend 239。操作员在 11 月 3 日确认“热力图和监控均正常”。本 PR 基于尚待合并的 PR #25，仅归档其后的已发布源码、回归测试和验收证据，不执行生产发布。

## 用户可见改动

- 主对话和数字员工的附件、知识库卡片共用固定一行高度的可纵向滚动区域；文字保持多行及独立滚动，发送后卡片靠左并保留边距。桌面与移动端工具图标和提示样式一致。
- 网页主对话和数字员工的联网搜索默认关闭；用户开启后才能使用 `web_search` / `web_fetch`。服务端校验请求选项，子任务继承设置；没有传入该选项的既有 IM／定时任务调用保留原行为。
- 账号 Token 总量使用万／亿显示，新增单日使用峰值、最长已结束任务耗时、连续活跃天数及 12 个月活动热力图。每天、每周、累计总量均使用方格图，悬停和点按显示数值；累计模式包含展示窗口之前的历史用量。
- 看板新增浅色模型调用监控和独立 OA 文生图接口监控，分别展示调用量、成功／失败、耗时、最近观测执行数和并发采样峰值。修复监控 HTTP 查询参数被整数 Literal 拒绝、导致 `minutes=15/60` 返回 422 的问题。
- 文件读取工具提前拒绝将图片／二进制当作文本读取，保留受限文本读取与清晰提示。这不会使非视觉模型获得图片理解能力。

## 数据与运行边界

个人用量查询使用已有账号索引、只读事务、限时聚合和缓存；按 Asia/Shanghai 的运行开始日期归属，已记录的进行中用量也参与统计。最长任务只取已结束运行。

模型和 OA 监控不增加业务数据库查询；采集在内存中计数，后台发布有界 Redis 快照，页面共用缓存查询。并发每 5 秒采样，可能遗漏短时尖峰；未接入的外部系统、服务端内部重试和远程视频任务执行并发不在统计内。上线前的历史并发不能回填，采集不可用不能显示成零。OA 后台任务状态复用已有执行链路，不额外轮询业务数据库。

本批没有数据库迁移，也没有发布海能 Work 数据湖授权、0023 授权表或 PPT Runner 更新。来源工作区中的暂缓代码没有纳入；41 个运行时文件取自封存的发布覆盖层和 Frontend 239 构建目录。
