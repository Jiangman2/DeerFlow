下面进入小节：7.4 用户作用域和 Agent 作用域。

当前分支会把用户 ID传入 Skill、Memory、知识库范围和权限相关逻辑。自定义 Agent 还可能拥有：

自己的模型。 - 自己的工具组。 - 自己的 SOUL.md 或提示词。 - 可用 Skill 白名单。 - 可更新 Agent 配置的 update_agent 工具。

Webhook 渠道会被限制使用自修改 Agent 的工具，避免外部评论者通过 Prompt 触发持久化配置变化。

下面进入小节：7.5 系统提示词不是一个固定字符串。

系统提示词通常由以下部分组合：

基础语言和行为规则。 - 工具说明和使用约束。 - Skill 说明或延迟发现提示。 - 子 Agent 使用说明。 - 当前运行模式。 - 知识库范围和引用要求。 - 非交互模式说明。 - Agent 自己的灵魂文件或自定义描述。

因此调试“模型为什么这样回答”时，不能只看 UI 上的用户问题；需要同时看最终模型配置、最终工具清单和最终 system prompt。
