## 实现边界

- RunJournal 声明 `deerflow_loop_bound`；子代理复制父 RunnableConfig、callback
  manager 的两种 handlers 后，只移除标记的回调。保留流式回调、线程/检查点
  lineage、用户/WeKnora/trace ContextVars，父回调列表不变。
- 同步隔离执行与后台任务入口共用过滤；复制失败发生在 pending 注册之前。
- 先取得隔离循环再创建 coroutine；提交失败（包括取消）关闭未调度 coroutine。
- 企业发布快照、知识授权、工具策略、沙箱 lease 释放和生产进程数未改。
- 惰性 Skill 激活、scheduler submit/capacity 重构、受信子代理审计代理仍另批完成。

cycle-breaking mock 掩盖实现；清理线程、scheduler 与 atexit 注册。

- 七模块（executor、steps、Journal、事件契约、imports、员工 Skill）：

  用例版本门禁影响；Windows 另缺创建符号链接权限，Linux 该安全用例已执行。
  不是运行平台的生产能力验收。
