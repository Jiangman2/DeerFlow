# Upstream Sync Batch 15 — BOM-Safe Sandbox Image Selection

## Scope

- Enterprise branch start: `e1bda401a`
- Recovery tag: `enterprise-pre-upstream-batch15-20260919`
- Official change adapted: `53f2a73d2`

## Behavior

- Remove a leading UTF-8 BOM before locating the top-level `sandbox:` block in
  `config.yaml`.
- Normalize CRLF line endings before extracting `sandbox.image`.
- Preserve the pinned enterprise default when the image remains absent or
  commented out.
- Keep the shell-only pre-pull path independent of synchronized Python
  dependencies.

## Enterprise adaptation

The focused test locates Git Bash using the repository's existing Windows test
pattern because this baseline does not yet contain upstream's newer shared
`tests.support.shell` helper. Subprocess output is decoded explicitly as UTF-8
so the script's status symbols are deterministic on a GBK Windows host.

## Operational impact

This changes only local/operator sandbox-image pre-pull selection. It does not
alter the runtime provider default, build or pull an image during tests, mutate
production, or change Kubernetes resources.
