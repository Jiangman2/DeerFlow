# v2.1.0 批次 27：Changed-output 终态验收及企业发布适配

依赖批次 17–26，适配官方 #4494 的最终语义，不整文件覆盖企业 worker/独立 PPT transport graph。

## 实现

- 新增 `runtime/runs/delivery.py`：新增/修改的 outputs 与可信实际发布回执对账。模型文字、历史 graph artifacts、任意工具和旧文件列表均不能代替发布。
- `present_files` 可以按目录匹配；平台 `generate_image` / `generate_video` / `browser_screenshot` / `web_capture` 只能按精确文件匹配。
- PPT Agent Host 仍持有实际验证、原子交付和配套预览的责任。Bridge 只在 authenticated transport 返回 completed 且 task/thread 身份匹配后写 `by_publisher.ppt_master_agent_host`，不伪造工具/模型步骤。
- Journal 拒绝关闭后的 late handoff、跨任务/线程和非规范输出路径；整批验证后才记账。关闭时释放相关引用。
- worker 的 before/after/review 快照保持相同排除目录；在 success 前核对，本轮有产物却无可信发布则 error。终态单例写入失败时，产物型 success 不被误报为成功。
- 人工确认等待仍可恢复；用户取消、原始执行失败、租约失权优先，不能被新 gate 覆盖。

## 验证证据

- 新 delivery 验收测试初始 19 失败、3 通过；PPT publisher 初始 15 失败。实现并修正后全绿。
- 扩大 Windows 联合回归：290 通过、5 跳过，19.83s。含新 delivery/PPT publisher、worker delivery/rollback/human-input/stream teardown/terminal cleanup、Journal/lease、媒体/present_files/PPT host、workspace IO/cancellation。
- 新增 compiled PPT graph → 真实 worker → Memory event store 集成用例；仅替换 authenticated transport 的网络响应，使用真实临时 outputs。测试产物是合成字节，不冒称真实 PPT/PDF 内容验收或外部 Agent/model 验收。
- 后续 Linux 合并批次 26–28：297 通过、1 跳过，75.16s；跳过的是测试依赖镜像缺少 Playwright 的真实浏览器用例。新 worker/PPT receipt 和 Linux symlink 用例实际通过。
- 最终 Windows 扩大联合回归：521 通过、5 跳过，22.00s。跳过为 2 个需要临时 PostgreSQL 的用例及 3 个 Windows 符号链接权限用例；本轮未启动 PostgreSQL，不把以往批次的真实数据库结果冒充本轮执行。与上列定向测试有重叠，不能相加为独立测试数量。

## 不夸大范围

官方通用最低标准是“至少一个 changed output 得到匹配发布”，不是所有文件都满足业务质量；PPT 既有严格交付验收不削弱。快照不可得/截断仍为 degraded observation；未接 event store 的执行路径不因此新增持久化证明。子代理可验证句柄、acceptance criteria、事件删除 fence 等仍待依赖批次。没有生产操作、数据迁移、镜像构建或上线授权。
