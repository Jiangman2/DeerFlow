# v2.1.0 批次 14：孤儿运行的流终止

适配官方 #4420 `c7538cfb35553aa20292f4d8636304f16ff14040`，目标仍为已锁定 v2.1.0。

- 启动/周期回收在原子接管中写 `orphan_recovered`。存储层已有这一可选字段契约，本批接通 manager 和 Gateway 调用链。
- 周期回收通过回调发送真实 END 并安排清理；扫描和回调单实例后台执行，不阻塞续租循环。关闭时共享退出预算，取消未完成回收并清理已登记的延迟任务。
- 跨 worker SSE/wait 每次心跳按已授权 record owner 刷新持久状态，只有明确的孤儿回收终态才合成结束；普通 success/error 不提前截断最后的数据、错误和 END。
- 企业 PPT runner 的独立启动仍不扫描并误伤普通 Gateway 的 NULL 租约 run；保留 Dashboard 读库关闭和跨 worker join 不自动取消的现有规则。
- 周期回收不回写线程级状态，避免覆盖同线程新任务。官方启动期线程投影仍仅位于请求服务前；跨进程线程投影的更完整 CAS 不能由这一限制替代。
- 修正历史合并分页：本地旧记录不再挤掉存储中较新的运行。
