## Behavior

- Add one canonical scheduled-occurrence status enum shared by API validation,
  repository filtering, and active/terminal status sets.
- Apply the selected status before SQL ordering, limit, and offset; include task,
  status, and page in the frontend query identity.
- Add a localized status selector to the existing enterprise run-history modal
  without replacing its owned card-grid/detail workflow.
- Treat only physical LF characters as JSONL record boundaries, preserving NEL,
  line-separator, and paragraph-separator characters inside event strings.
- Recognize a top-level Browser tool name anywhere in its YAML mapping while
  ignoring nested `name` keys.
- Keep answer text plus real reasoning in the assistant response during streaming,
  and keep thinking-only content in processing until displayable answer text exists.
- Treat authoritative clarification results as run boundaries and render their
  introductory context once outside the processing disclosure.
