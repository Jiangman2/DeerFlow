## 实现与企业差异

- 默认直接执行。任务复杂、回答长、可拆分本身不足以要求委托；明确比较
  专长、独立并行延迟、父层上下文隔离收益与启动/上下文/协调/验证成本。
- 使用最少必要子代理。单名额仅提供专长/隔离收益，不声称并行提速；多名额
  不再强制至少两个。依赖任务、重叠写入及共享可变状态不得同批并行。
- 每批后重新判断，剩余预算不是配额；completed 不等于验收成功，逐条检查
  holds / does not hold / UNVERIFIED 及原始回执。
- 保留企业显式 Ultra/并行请求的首批 task 规则，但不授权越过硬上限、
  依赖/重叠写入限制或新增外部副作用。角色说明继续转义自定义元数据。
- 仅在实际存在可用角色时生成委托提醒。保留企业中文/产品名/Skill/PPT
  提示及回执关闭分支；不提前宣传尚未接线的 batch_task 或 snapshot API。
