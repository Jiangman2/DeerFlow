# 批次 44：文件读写门禁取消与工具执行清理

按官方 #5395 `dfc8e7242`（锁定 v2.1.0 最终源码）适配
read-before-write 的 _await_off_thread / _acquire_gate_lock。
保留企业及批次 43 的授权、员工、归属逻辑。

- 等待 threading.Lock 的 worker 不可直接取消。记住首次取消，等待真正获取锁
  后释放，再传播取消；否则后台迟到的 acquire 会永久占锁。
- 写入前检查及读回哈希 worker 完成之前不释放门禁。晚到的授权错误不能盖掉
  用户的首次取消，重复取消也不提前退出。
- 异步沙箱工具调用现有 run_sync_lifecycle_operation，工具体的后台线程结束
  之前，不退出授权 scope、不释放外层文件锁/执行租约；没有复制一套租约实现。
- 引入官方 7 项取消回归；唯一适配是选择显式 disabled 配置 fixture。
  补充 2 项真实异步工具体与门禁组合测试（正常结束和晚到异常）。
