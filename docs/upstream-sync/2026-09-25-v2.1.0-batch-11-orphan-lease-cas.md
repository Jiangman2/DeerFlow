1. 扫描后原 owner 续租，不能覆写为 error。
2. 扫描后正常完成，不能覆写终态。
3. 扫描后记录已删除，不能重建该运行。
4. 两个回收者拿到同一个过期快照，只有一个成功 claim/报告回收。

原“状态写失败”测试改为实际新边界“takeover claim 失败”，仍断言有限重试、无虚假恢复、原状态不变。Ruff 与 scoped diff 检查通过。
