# 批次 49：循环告警的主 / 子代理日志接线

适配锁定官方 #5127 与 #5214 的可信归属边界。保留企业版已有的文件变更
进展识别、重复失败恢复、终止 metadata 和 hard-stop，不以遥测替换执行门禁。

- 相同调用集、工具高频、企业版 unchanged-failure 告警 / 硬停止写入现有
  middleware:loop_detection 事件，记录工具名称、次数、阈值与检测层，
  不记录工具参数、失败输出或原始签名。
- 服务端私有 recorder 决定子代理归属；仅有调用方 is_subagent/agent_id
  字段不能伪造归属。主执行沿用真实 RunJournal。
- 子代理不接收原始 journal；受限桥接深复制事件参数，在父 journal 所属
  loop 入队。关闭 fence 拒绝迟到事件，已接受回调先 drain，绝不在子 loop
  直接调用 SQL journal 兜底。日志写入失败不能解除执行硬停止。
- task 工具构造、提交、writer、轮询、取消及正常结束均关闭 bridge；提交后
  writer/轮询失败仍请求取消与延后清理，保留已有 terminal/usage 清理流程。
