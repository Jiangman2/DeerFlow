# Upstream Sync Batch 12 — Repeated-Cancellation Run Drain

## Scope

- Enterprise branch start: `a42b605d8`
- Recovery tag: `enterprise-pre-upstream-batch12-20260919`
- Official change adapted: `6a94bef90`

## Behavior

- Remember the first cancellation delivered while Gateway is draining active
  runs.
- Absorb later cancellation requests until the internally bounded
  `RunManager.shutdown()` task reaches a terminal state.
- Propagate the original cancellation only after the drain is safe, preventing
  checkpointer and database teardown from racing active terminal writes.
- Preserve the existing best-effort contract for a drain failure when no
  cancellation was requested; after cancellation, log the drain failure and
  still propagate the remembered cancellation.
