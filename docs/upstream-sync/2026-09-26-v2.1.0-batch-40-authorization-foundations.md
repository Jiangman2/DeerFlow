## 行为与边界

- RBAC 配置严格校验，deny 优先；未知角色拒绝。已知角色未声明某资源策略时，
  按官方语义不限制该资源。未生成企业角色映射或默认 allow 策略。
- Provider 类发现可以在线程卸载，实例构造须留在使用它的事件循环；无全局实例缓存。
- 工具过滤保留原对象、顺序，Provider 不能注入候选之外的工具；格式错误和异常
  默认 fail-closed，仅显式 fail-open 才保留工具。
- Layer 1/2 共用现有 Principal 构造规则，不把字符串 true 当内部身份。
- authorization.enabled 仍默认 false；本批没有配置、生产开关或工作负载变更。
  工厂尚未接入主代理、子代理和嵌入客户端；员工/知识授权仍是独立强制边界。
