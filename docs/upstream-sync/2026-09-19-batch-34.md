# Upstream sync batch 34

## Scope

Adapted the useful behavior from upstream commits `3cfc9c58f` and
`9f79ddf9b`: model-bound Gateway requests outside `/api/langgraph/` must not
inherit nginx's 60-second read timeout.

The generic thread API now allows long compaction, suggestion, and run-wait
requests. The Skill API allows per-file LLM security scans during install,
edit, and rollback. The `/api/` catch-all allows long run waits and input
polishing calls.

## Enterprise adaptation

The change is applied to Docker, local-development, Helm, and the enterprise
`k8s/local-pvc` production configuration. Existing route-specific boundaries
remain unchanged, including 660-second streaming routes and the intentionally
bounded OA integration routes.

This batch changes proxy configuration and regression tests only. It does not
change application logic, Kubernetes workloads, databases, WeKnora, SkillHub,
or the production browser/MCP-browser policy.
