# v2.1.0 批次 33：Journal 所属循环与显式刷写互斥前置

官方来源：#5214，`14c9d44440780e63563e935046db8708e121a5b1`。
本批只适配其 Journal 生命周期前置，不把整个工具阶段审计功能标为完成。

## 实现及企业保留

- 构造时捕获当前事件循环；子线程 middleware 记录投递回所属循环，不直接并发修改 buffer。所属循环关闭或停转后丢弃迟到事件。
- `flush()` 期间禁止阈值触发第二个自动写任务，finally 恢复标记；保留失败批次重试、进度刷写及 canonical response 提交顺序。
- 已关闭/失权 Journal 的事件仍被拒绝，异步关闭清理与企业交付回执保持不变。同步构造（未捕获 loop）的旧调用方式仍兼容。
- 未增加数据库迁移、事件类型、worker 数或生产开关。没有把 Journal 的所有 API 宣称线程安全，也不以该标记代替多个显式 flush 调用者的生命周期约束。
