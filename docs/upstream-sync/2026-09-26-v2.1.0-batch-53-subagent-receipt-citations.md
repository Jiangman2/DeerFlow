## 实现

- Executor 发布运行中回执快照；完成报告使用该报告实际看到的 citing-turn
  ledger，不把压缩后的 ToolMessage 重新编号当作同一个 rN。
- 包含已执行工具的 chunk 先收集，再观察取消；保留企业 cancellation-safe
  stream close / Sandbox lease release、usage 结算、迟到结果终态保护。
- 回执更新/取快照受锁保护并复制，超时首个终态获胜。额外关闭一条误判路径：
  completed 快照缺失或畸形时清除运行中临时 ledger，不复用其编号。
- Executor 的配置读取缓存为同一快照，使 prompt、middleware 和 harvest
  对 receipts_enabled 一致；关闭时不收集、不要求引用。
- 内置和自定义子代理均附加官方报告约束（引用和可核对交付句柄）。
  task 在截断长摘要之前核对完整报告，将结构化证据附到 ToolMessage，
  durable delegation ledger 显示未知/失败引用或 UNVERIFIED。
- Gateway 外部输入不能伪造 child receipts/verdict；旧状态/枚举及无回执
  的历史保持兼容，失败/取消/超时不能携带 completed citation verdict。

`citation_resolved` 只证明引用解析到执行证据，**不等于正确答案、验收通过
或不可篡改签名**。缺失快照不回退猜测；尚未接 acceptance checklist/judge，
不能声称所有可验证执行能力完成。
