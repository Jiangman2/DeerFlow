# Upstream Sync Batch 41 — Complete Streamed Tool Calls

## Scope

- Enterprise branch start: `041818bac`
- Recovery tag: `enterprise-pre-upstream-batch41-20260919`
- Official behavior adapted from `529b0e05e`.

## Behavior

- Tool calls whose names or JSON arguments arrive as multiple
  `AIMessageChunk` fragments are no longer emitted from each partial chunk.
- The embedded client records that a tool call is pending and emits it once
  from the assembled values snapshot, with its complete arguments.
- The assembled event retains the existing enterprise token-usage attribution
  metadata and participates in the same cross-mode message-id deduplication.
- Providers that emit a complete non-chunk tool call, or a message without an
  id that cannot be correlated to a snapshot, retain their existing behavior.

## Enterprise adaptation

The correction is layered onto Batch 32's later-node appended-text handling
and the enterprise additional-kwargs delta tracker. It does not replace the
current stream event schema, tracing, authorization context, model factory, or
TUI behavior.
