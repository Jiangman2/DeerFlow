## Behavior

- Remote E2B and BoxLite glob/grep commands preserve the search command's own
  status across `head`, distinguish missing roots from genuine no-match results,
  and reject unreadable/partially traversed trees.
- The bounded command reads one raw line beyond its cap. The parser drops that
  line and reports truncation, so Python-side ignore/glob filters cannot turn an
  incomplete search into a false complete empty result.
- Remote glob follows a symlinked starting root with `find -H`, matching the
  corrected list-directory behavior without recursively following arbitrary
  symlinks.
- Tool output now calls an empty-but-truncated result incomplete instead of
  saying that no files or matches exist.

## Scope boundary

truncation behavior. No Provider absent from this enterprise branch is added.
