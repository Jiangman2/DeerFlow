# Upstream sync batch 35

## Scope

Adapted the resource-lifecycle correction from upstream commit `94110e5dc`:
agent streams are now closed deterministically before a run or delegated task
reports completion, cancellation, or failure.

## Enterprise adaptation

The shared close helper is used by both the enterprise Gateway run worker and
the subagent executor. It supports runtimes with no close hook, synchronous
hooks, and asynchronous hooks. A close failure becomes the primary failure on
an otherwise successful execution, but cannot replace an existing stream error,
host cancellation, or explicit run abort.

The existing enterprise stream modes, clarification handling, goal
continuations, token accounting, durable step capture, Sandbox policy, and
result contracts remain unchanged.

This batch changes local runtime code and tests only. It does not mutate any
production workload, database, Kubernetes object, WeKnora, SkillHub, or
Sandbox image.
