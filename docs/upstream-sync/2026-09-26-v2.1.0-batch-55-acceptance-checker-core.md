## 实现与边界

- 接入 acceptance_checks：限定当前 workspace / outputs 文件，拒绝外部路径、
  越界符号链接和非普通文件；先探测大小，超过 50,000 字节不加载完整内容。
  file_written 的大文件另需有界可读探针。不能探测则 UNVERIFIED。
- tests_passed 对照具体命令、退出状态和输出摘要；排除 echo/comment 伪造、
  截断命令、跳过目标、缩小测试范围、输出重定向/归属不明、含状态污染的
  前置命令、Windows 路径和 shell 语义歧义。仅 fresh-shell 证据可肯定核对。
- Sandbox capability 默认 unknown，LocalSandbox 声明 one-shot。AIO 暂无普通
  命令 provenance 声明，保守 UNVERIFIED；不将文件探针的 fresh session 当作
  所有之前命令都是 fresh 的证据。
- 更正批次54预审：AIO 不需要特判 `_DEERFLOW_SIZE_PROBE`，其既有非空 env
  分支已走独立 bash.exec 会话并 finally 关闭。本批经真实 AioSandbox 方法 +
  mocked SDK 验证两次探针会话不同且关闭，不改此前写入失败的 AIO 文件。
- 企业补强：默认大小/可读探针在本地 stat/open 或远程调用前经过现有授权
  scope；缺配置/拒绝访问不读取、不转换为“不存在”。错误不回显 provider
  凭据；尺寸只接受有界 ASCII 数字。存储 verdict 校验来源、长度、标签、
  行边界、family、checked/holds 及聚合一致性，不相信伪造 all_hold。

`holds` 仍是执行证据，不是答案正确性或完整交付保证。保留上游已声明局限：
裸 runner 名依赖 PATH，测试脚本自身语义受信；存在探测/读取间文件变化窗口。
不自动重新执行用户测试命令，不启用 judge，不改变现有生产运行。
