## Behavior

- Share one explicit new-run HumanMessage boundary between delegation capture
  and stale-delegation closure.
- When a later user turn starts, mark an earlier run's `in_progress`
  delegation `cancelled` if no matching `ToolMessage` was ever persisted.
- Preserve resumed runs, entries from the current run, legacy entries without
  a run id, and entries with any structured or legacy reply.
- Stop injecting the false "do NOT delegate again" instruction for a task that
  was actually interrupted before returning a result.

## Operational impact

This changes only checkpointed delegation status when a new user turn proves
that an earlier task call never produced a tool reply. It does not cancel live
work, mutate production, change databases or Kubernetes resources, or infer
legacy outcomes from free-form text.
