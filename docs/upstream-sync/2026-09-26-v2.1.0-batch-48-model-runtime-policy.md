# 批次 48：模型使用授权接入主 / 子 Agent 与嵌入式客户端

续接批次 47，适配锁定官方 #4540 主 Agent 的实际 model:use 行为，并覆盖
企业分支另两个独立模型构造入口。模型目录筛选不能替代执行授权。

- 主 Agent 在 request → employee config → default 名称解析之后、创建模型
  之前授权，覆盖普通与 bootstrap；元数据记录最终选择的模型。
- 新共享同步/异步 helper 对默认、未知名称回退、显式模型都校验 model:use。
  fallback 先限制为配置目录里的可见子集，再逐个检查 use，不接受 provider
  注入目录外名称；返回顺序遵循配置目录，不依赖任意 provider 返回顺序。
- 子代理配置模型 override 和继承模型在构造实际 LLM 前检查，使用实际
  child-loop provider/身份；异步 aauthorize 留在所属 loop，同步 filter off-loop。
- 嵌入式客户端创建图前同样授权；create_chat_model 使用该客户端的显式
  AppConfig，避免授权与模型实例从不同全局配置读取。既有跨用户 cache key
  与授权开启时每次重建保持不变。
- 明确 disabled 才跳过；损坏策略/身份拒绝。合法 fail-open 只用于尚未明确
  deny 的 provider 故障；已经 deny 的原模型不能因后续 fallback 故障而复活。
  这是保留企业前批 deny 优先边界，未复制上游无可用候选时 blanket fail-open。
  GraphBubbleUp/取消继续传播，异常日志不包含 provider secret 文本。
