# 批次 45：Gateway 辅助沙箱授权

对齐锁定 v2.1.0 的 request sandbox gate 行为，保留企业解析、只读审阅和
独立 PPT Runner。未照搬官方 config-error => disabled、anonymous => skip
的兼容 fallback，也未引入跨 event-loop 的全局 provider 实例缓存。

- 新的请求 helper 使用实际认证用户；storage owner、请求 query/body、伪造
  internal header 均不授予执行身份。internal 由 auth_source 证明；有归属的
  internal 调用必须解析真实且未停用的用户，解析失败不能升级到 default_role。
- 上传同步拒绝时仍可保存主文件、使用主机/企业解析器；同一请求不能绕到
  legacy .doc 的 LibreOffice 再启动沙箱。该 fallback 对已有 client 也重新检查。
  必须有解析结果的上传仍按原有事务回滚并返回 503，不能提交空白解析。
- Live Preview 修改操作在普通 discovery 和独立 Runner 转发前执行 gate。
  普通下载/只读预览的 read 权限不变，Gateway 不接管 Runner 的生命周期。
- 本地没有官方的 artifact-edit 路由，不复制针对不存在路由的测试凑验收。
