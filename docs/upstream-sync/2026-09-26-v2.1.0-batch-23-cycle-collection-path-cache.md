# v2.1.0 批次 23：终态 GC 与动态路径缓存

继续官方 #5112，固定参考 v2.1.0 commit `345f08be00c8a9495079b732a39b46aa9af1584e`。

- worker 最终释放运行引用后调度 GC；process-wide 10 秒合并、空 Context timer/task、WeakSet loop 注册、executor 执行、100ms 慢调用日志。补充异常日志并始终释放 single-flight 标记，避免无人领取的后台错误。
- 工具输出脱敏此前仍把每个用户/线程/ACP 根目录纳入正则缓存。现在仅静态源进 LRU16；动态源走现有直接扫描器；根路径拼写解析 LRU256，保持分隔符、路径边界、最长前缀与脱敏顺序。
- virtual root 的父目录运算采用上游 lexical POSIX/Windows 路径处理，不把大量线程组件交给 pathlib intern。
- LocalSandbox 自身的反向直接扫描已存在，没有覆盖它。其剩余 realpath/pathlib 实现差异仍要完成安全等价验证，不把整个 #5112 标成结束；扩展生命周期也仍未全接通。
