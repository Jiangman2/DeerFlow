## 实现

- 同步官方 `effective_subagent_concurrency`，安全上限支持1–64，但实际
  task-call上限仍受进程启动时的 `subagent_runtime.max_running` 限制。
  默认仍为3，不把配置支持64误写成默认并发64。
- 普通/创建向导 Agent 同一份启动容量传给 prompt 和 middleware；配置热重载
  不能扩大或缩小正在工作的进程容量。嵌入式 Client 保存启动快照，reset
  只清理 Agent 缓存，不重新配置执行器。
- 保留每run默认6/可配置1–50的总委托限制、显式并行中间件、企业授权和
  Skill/知识范围。没有增加 task 调用权限。
- 本地补齐嵌入式 context 合并：configurable、config.context、显式context
  按优先级合并，同一副本用于提示与middleware；不修改调用者原始对象。
