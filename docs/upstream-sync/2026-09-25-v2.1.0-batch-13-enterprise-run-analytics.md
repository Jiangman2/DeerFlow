# v2.1.0 批次 13：内部 reservation 与企业运行统计隔离

批次 12 引入内部 `checkpoint_write` 行，企业版 Dashboard、管理员和 observability 的直读 SQL 不能把这些行当成用户请求、失败或 token 消耗。本批为 #4437 的企业关联适配，不冒充另一个官方 PR。

## 实现

- Dashboard 会话、失败、排行、总览及事件来源限定 `operation_kind=run`。会话左连接过滤位于 JOIN 条件，仍保留只有内部操作的零运行会话。
- 管理员运行计数和 observability traces、analytics、usage、source、snapshot 排除内部行；单条内部 diagnostics 不对外暴露。
- 日/小时 rollup 输入、增量变化扫描和最早源时间只取真实 run；不删除内部行，保留恢复/审计证据。用户删除的原有清理范围未被缩窄。
- 保留每个查询原有用户/管理员权限过滤；未启用任何生产 rollup 后端。
