# v2.1.0 批次 25：浏览器私有循环兼容与回归续接

这是全仓库回归发现的企业 Windows 兼容修复，不冒称新增官方 PR。官方 v2.1.0 的 browser private loop 使用 `asyncio.new_event_loop`；企业 Gateway 为数据库兼容可能使用 Windows Selector，但它不支持 Playwright driver 子进程。现在仅 browser private loop 在 Windows 选 Proactor，Linux 和进程全局 policy 不变。

## 证据

- 新增 3 项，Windows factory 与真实 child process 原先失败，Linux factory 原先通过。修复后都通过，未修改进程 policy，也未降低原浏览器断言。
- Browser private loop、完整 browser automation、Gateway launcher：**56 通过、无跳过，9.68 秒**。包括已有真实 Chromium 的本地 `data:text/html` 点击、输入、读取、截图，未访问企业网站/公网模型。
- 批次 22–24 与先前 680 项主回归统一运行：**933 通过、无跳过、1 条 Starlette/httpx 弃用警告，47.33 秒**。包括本机 Memory/SQLite/PostgreSQL、终态清理、GC、路径缓存、取消/租约、Journal/回执、独立 PPT runner 等；不是将多个重叠测试数字相加。
- Linux 原生 tmpfs 311 项结果见批次 24，不与上述 Windows 数字累计成独立总数。
- 本轮 scoped Ruff 和 diff check 通过。没有修改平台权限测试来伪造 Windows 全绿，没有向 live model 测试提供生产凭据。
