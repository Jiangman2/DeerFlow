# 批次 59：子代理容量控制器前置

来源为固定官方 v2.1.0 `345f08be00c8a9495079b732a39b46aa9af1584e`
的 subagent_runtime 配置和 subagents/capacity.py。此批只完成控制器和配置
契约，**Executor / Gateway / Embedded 启动接线尚待下一批**。

## 实现

- 默认进程3个运行名额、64个异步排队名额、300秒排队超时；可配置有界
  queue / reject。FIFO 转交名额、超时撤队、释放名额后才传播连续取消。
- 同配置初始化不清空运行队列；运行中拒绝改配置/迁移事件循环。跨线程
  snapshot 不迭代变化中的 deque。新增 AppConfig 字段及 startup-only 注册。
- 本地增强：控制器复制配置，避免调用者修改对象绕过启动快照。
- 本地增强：排队者刚收到转交名额且发生超时/取消，撤队等待锁时再被取消，
  原实现会遗失运行名额；确定性回归已复现两种路径。撤队与普通释放共用
  cancellation-safe drain，确保归还完成后再传播取消。

## 验证

引入官方10项控制器测试，新增15项配置边界/快照/单例/零队列/FIFO/连续取消
回归。修复前新增测试3项失败，分别证实配置别名和两种名额转交取消问题。

8模块最终回归：capacity、execution capacity、capacity boundaries、reload
boundary、app config reload、config version、executor、timeout config：

- Windows **213 passed / 1 skipped**，5.90s。
- Linux **213 passed / 1 skipped**，39.01s；已有镜像、断网、非 root、只读源码，
  1 CPU / 3 GiB；容器已自动移除。
- 唯一跳过为 LangGraph >=1.2.6 root-lineage 版本条件；不计入通过。
- Ruff check/format、scoped diff check 通过。
