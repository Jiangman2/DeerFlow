# Upstream Sync Batch 29 — Reliable Windows Local Commands

## Scope

- Enterprise branch start: `7976a0dcc`
- Recovery tag: `enterprise-pre-upstream-batch29-20260919`
- Official behavior adapted from:
  - `1c219b686` — scope MSYS path-conversion exclusions

  - `93f9ed3d8` — force UTF-8 PowerShell console I/O

## Behavior

- Windows LocalSandbox output is drained through the same 10 MiB bounded
  capture contract as POSIX commands instead of being accumulated without a
  limit by `subprocess.run`.
- A Windows timeout terminates the complete child process tree and retains the
  existing user-facing timeout notice.
- PowerShell input/output is explicitly UTF-8, including Windows PowerShell
  5.1 on Chinese hosts, while cmd/Git Bash retain their locale encoding.
- Windows text-stream newlines are normalized consistently.
- Git Bash excludes only configured safe DeerFlow virtual roots from MSYS path
  conversion. It no longer disables conversion globally for host-native CLI
  shims.
