# Upstream Sync Batch 17 — Reject Nonexistent Local Schedule Times

## Scope

- Enterprise branch start: `1da94a2d1`
- Recovery tag: `enterprise-pre-upstream-batch17-20260919`
- Official change adapted: `73590a626`

## Behavior

- Round-trip one-time wall-clock input through the selected timezone before
  accepting it.
- Reject invalid calendar values, unknown timezones, and local times skipped by
  daylight-saving transitions.
- Clear the emitted schedule spec and show localized inline feedback while the
  value is invalid.
- Disable both create and edit submission until a valid instant is restored.
- Preserve Batch 16's exact original timestamp when an edit is reverted.

## Enterprise adaptation

The enterprise create page already rejected an empty schedule spec. The same
guard is added to its modal edit workflow, and the official browser scenario is
adapted to open enterprise create/detail surfaces explicitly. Scheduler backend,
database, model selection, and pinned-agent context remain unchanged.
