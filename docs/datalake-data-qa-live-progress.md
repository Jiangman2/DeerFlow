# 智能问数实时进度

本次实现 `datalake_data_qa` 在现有工具调用区域中的实时状态，不改变新问数接口、业务答案、授权规则或禁止外部查询替代的限制。`datalake_smart_qa` 保持原有行为。代码与本地验证完成不等于生产验收。

## 链路与必要改动

原有后端将问数事件收集完才返回工具结果；HTTPX 的固定 8192 字节分块还可能积攒小 SSE 事件。前端已订阅 LangGraph custom 流，但普通工具区域没有问数增量事件的存储、关联和渲染逻辑。因此仅在最终返回值加入过程字段无法满足需求，本次需要后端和小范围前端适配。

现在的链路是：上游 SSE → `data_qa_stream.py` 按传输块解析 → `DataQAProgress` → ToolRuntime 的 `stream_writer` → 现有 Gateway custom SSE → `useThreadStream` → 当前工具步骤。没有新增接口、轮询、数据库表或 ConfigMap 字段。

每条事件仅有固定类型、工具名称、会话 ID、运行 ID、工具调用 ID、阶段代码和递增序号。前端先经过现有会话归属检查，再校验运行及调用身份；同一调用去重、拒绝倒序事件和终态后的重放，保留最多 8 个状态、100 个调用。新运行清空上一轮进度。原始上游文字、SQL、实体字段、内部推理、密钥和 Token 不进入进度流。

## 有依据的阶段

| 依据 | 展示 |
| --- | --- |
| 授权、参数及密钥检查通过，开始调用 | 正在调用智能问数，等待查询进展…… |
| 收到非 end 节点的 answer 事件 | 智能问数正在处理您的查询 |
| 收到 end 节点的 answer，或兼容协议的 answer delta | 正在整理问数回答 |
| 完整结果被现有协议校验接受 | 调用完成、无可用结果或需要补充条件 |
| 上游错误、超时、用户取消、流意外结束 | 对应失败、超时、取消或未收到完成状态 |

现场脱敏样本已包含非 end 与 end 的 answer、workflow_finished 事件，但没有可核验的中间节点业务类型。因此不从正文猜测“意图识别”“匹配字段”“执行 SQL”，不编造百分比。没有中间事件时继续显示等待；未知进度字段不会改变正常结果解析。普通进度不能清除错误或证明最终成功。进度观察者关闭也不改变原工具结果。

## 界面变化

| 改造前 | 改造后 |
| --- | --- |
| 普通工具名称及最终返回，等待中缺少查询进展 | 当前工具区域立即显示等待；事件到达后更新最新状态 |
| 无独立的问数阶段列表 | 默认只显示最新状态，可展开少量去重步骤 |
| 工具运行与智能体回答状态不易区分 | 工具终态立即停转，智能体仍可继续生成最终答案 |

最终业务回答沿用原消息区域，不在步骤中重复显示。进度是本轮 UI 状态，不补写历史；刷新后最终状态可从 ToolMessage 恢复，中间历史不承诺重建。取消沿用原有停止行为，本次没有新增上游取消 API，也不宣称关闭页面即可撤销已经提交的服务端查询。

## 验证记录

- 后端 92 项：AppForge、问数协议、授权/来源策略及新进度测试通过。覆盖无中间事件、成功、空结果、澄清、失败、超时、取消、观察者关闭、原结果兼容与敏感文字不进入进度。
- 真实异步 LangGraph ToolNode 测试在同步工具尚未返回时收到 `processing` custom 事件，再释放工具完成；小于 8 KB 的分块测试也在下一块尚未读取时断言进度已产生。
- 前端 11 项：会话归属、运行/调用隔离、去重、终态冻结、复用调用 ID、新轮状态、限量历史和各结束状态通过。前端 ESLint/TypeScript 检查通过；后端修改通过 Ruff。
- Playwright 实际聊天页面测试在 1440×900 与 390×900 通过：等待 → 处理中 → 整理回答 → 展开 3 个阶段 → 完成。每阶段均先断言可见再发送下一事件；完成时 HTTP 流仍未关闭，工具加载已停止。采用合成 SSE，不包含实际井数或生产凭据。
- 测试路径：`tests/e2e/data-qa-progress.spec.ts`。`live-stream-evidence` 附件记录页面地址、标题、各状态可见时间、流是否仍打开及浏览器日志。截图写入运行者指定的 `DATA_QA_SCREENSHOT_DIR`，不提交截图二进制。本机使用已核对属于此 PR 工作树的 `http://localhost:18143` 开发服务；Browser 插件技能不可用，使用仓库 Playwright。

生产尚未切换这项进度功能。发布需要兼容的 Gateway 与 Frontend；不需要因该功能更换 ConfigMap 或密钥。旧前端会忽略新增事件，新前端对旧后端保留等待/最终结果回退。正式验收应由有数据湖权限的用户查询“中海油有多少口井”，确认至少两个有依据的实时阶段早于最终答案、最终数值来自实际接口，并测试关闭权限、取消及刷新。本地合成流测试不替代该业务验收。
