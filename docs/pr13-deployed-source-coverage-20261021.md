## “主目录还有未提交内容”的实际含义

主目录和 PR 工作树处在不同分支，不能直接把主目录的整个差异叠加到 PR：

- `docs/upstream-sync/` 含上游对照和源码快照。
- `release/ppt-runtime-repair-r1/`、`release/portal-ppt-hotupdate-20261017/` 含大量临时测试和构建内容。
- 内网浏览器、Sandbox 网络配置仍有用户暂停的候选工作；DeepSeek V4.1 仍有服务与视觉验收缺项。源码若已进入 PR，也不等于已经启用生产。
- 未引用的导航图标候选资源、OCI 归档、压缩包、Office 临时锁文件不等于运行源码。
- 主目录另有 WeKnora/DocReader、容量与部署配置修改。它们不能仅凭目录名被判定为临时文件，也不能在缺少当前发布依据时覆盖 PR 中的基线。

**全环境覆盖仍待核对的边界：**本轮没有取得整个集群所有服务的最新部署清单，未将主目录全部 WeKnora/DocReader/容量调整与最终生产回执逐一绑定。因此本记录只证明表中这一系列热更的提交和指定源码锁覆盖，不能宣称所有服务器、所有历史热更已经完成逐项归档。应保留这些待核对项，不以“素材”名义遗漏它们。
