本批记录已安装的公共 data-analysis Skill、Frontend 234 的网页数据湖授权校验，以及 Gateway 400 / Frontend 235 的核心修复。服务端成功回执于 11 月 2 日收到；这次 PR 本身不再次部署。暂缓的海能 Work 数据湖授权、0023 授权表迁移和当前另行处理的数字员工附件布局均未纳入。

## 发布内容

- 网页数据湖：启用前验证 token 请求和新的 no-store session 响应，在共同的 60 秒期限内收到明确授权才启用；刷新和页面生命周期变化后不能通过 localStorage 恢复权限。
- 数据分析：用现有 openpyxl 离线读取 XLSX，再将临时 CSV 导入 DuckDB 做统计，避免运行时下载 spatial 扩展。保留日期、前导零标识、多工作表及源文件；旧 XLS 须显式转换。
- 看板失败列表：无筛选计数直接统计运行标量，移除全历史外连接；先分页再读取身份和有界错误摘要。前端限制响应大小、等待时间和并发翻页，失败后可重试原页，不把失败总数显示为零。
- 执行预算：网页请求和默认服务端上限支持 10000 步；更低的显式服务端上限仍优先，省略请求预算时的默认 100 保留。生产配置单独从 2000 改为 10000，循环保护保留。更高上限可能增加最长运行时间与消耗，不能解决不收敛循环。
- 文件交付：结构化含空格路径不再额外生成截断的裸路径声明，仍要求文件真实存在并完成发布。它不等于解决所有文件生成或 PPT 失败。
- 超时：所有模型共用明确的未完成提示及终止标记；GLM 补充总请求期限分类。超时参数保留，不自动重放不确定的操作，也不声称已消除服务端或网络超时。
