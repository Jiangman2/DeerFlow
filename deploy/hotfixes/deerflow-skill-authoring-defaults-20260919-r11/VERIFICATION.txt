  `data.DeepSeek_V4_API_KEY`; all other Secret fields are preserved.

  `slug`, namespace, or owner column is referenced.

- No existing Sandbox Pod is changed or deleted.
- Rollout requires zero active DeerFlow/OA work and repeats the gate after
  backup and immediately before workload changes.
- Errors and INT/TERM after the first mutation invoke the same exact rollback.
- The Frontend source patch runs with the Node.js runtime available in the
  immutable production Frontend image; it does not require Python in that image.
- The PPT Runner preservation check opens a disposable lock through the live
  `_open_lock_file()` helper and verifies the returned mode is exactly `a+`.
- The image importer preserves its caller-supplied artifact directory after
  loading immutable image names from `IMAGE_LOCKS.env`.

  `name: deepseek-v4-flash` model item, accepts the exact observed 2026-09-19

  immutable-image preflight and live status checks; backslashes cannot be
  consumed as basic regular-expression escapes.
